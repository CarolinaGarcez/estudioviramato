# Vira Mato — Estúdio Criativo

**Ideias em movimento.**

A Vira Mato é um estúdio criativo que conecta **design, comunicação e tecnologia** para transformar ideias em experiências digitais, visuais e funcionais.

Este repositório reúne o site oficial do estúdio, desenvolvido como um espaço para apresentar nossa identidade, nossos serviços e os projetos que fazem parte da nossa trajetória.

## Sobre o projeto

O site foi pensado para traduzir a identidade da Vira Mato em uma experiência digital autoral, com elementos gráficos, movimento, interações e uma linguagem visual própria.

Mais do que uma vitrine, é um espaço em constante construção e experimentação.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro
- Git e GitHub
- GitHub Pages para publicação

## Estrutura do site

- **Início:** apresentação da Vira Mato e do conceito *Ideias em Movimento*.
- **Sobre:** identidade, propósito e visão criativa do estúdio.
- **Projetos:** trabalhos e experiências digitais desenvolvidos.
- **Serviços:** soluções em design, comunicação e tecnologia.
- **Quem está por trás:** apresentação da fundadora.
- **Contato:** canais para conversar sobre ideias e projetos.

## Projetos em destaque

- **Rúbia Times** — experiência digital comemorativa.
- **Equilibrivm Experience** — experiência digital para um evento.
- **Keep Going** — projeto experimental e interativo.

## Desenvolvimento

O site é desenvolvido e mantido por **Carolina Garcez**, fundadora da Vira Mato, com foco em direção criativa, design de interfaces e desenvolvimento web.

A versão atual utiliza tecnologias web nativas e uma estrutura estática. Futuramente, o projeto poderá evoluir para uma arquitetura com Laravel e Blade, conforme as necessidades do estúdio.
