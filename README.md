# Vira Mato — Estúdio Criativo

Repositório do site oficial do Vira Mato — Estúdio Criativo.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro

A primeira versão será uma página estática, preparada para publicação no GitHub Pages. A estrutura também considera uma possível migração futura para Laravel + Blade.

## Estrutura

```text
index.html
css/
  reset.css
  variables.css
  style.css
js/
  main.js
assets/
  logo/
  imagens/
  elementos/
  icons/
  fonts/
```

## Executar localmente

Abra `index.html` em um navegador. O projeto não exige instalação de dependências nem etapa de build.

Os caminhos de CSS, JavaScript e assets devem permanecer relativos para funcionar também quando o site for servido em um subdiretório do GitHub Pages.
